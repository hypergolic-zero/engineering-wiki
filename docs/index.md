# Exergon Engineering Codex

**Engineering at the edge of curiosity.**

A public library of engineering methods, system-design thinking, reproducible experiments, and technical notes.

## Explore

- **Aerospace Systems:** spacecraft architectures, mission-level trades, and verification approaches.
- **Propulsion:** fundamentals, modeling methods, and non-confidential design notes.
- **Avionics:** interfaces, fault management, and architecture patterns.
- **Embedded Systems:** real-time software, firmware, and test practices.
- **Computational Physics:** numerical methods and reproducible simulations.
- **Engineering Methods:** reviews, requirements, modeling, and experimental discipline.

!!! note "Public documentation only"
    This site intentionally contains no confidential, controlled, proprietary, or personally sensitive material. Restricted notebooks will be stored and deployed separately with authentication.
